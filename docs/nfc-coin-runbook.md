# NFC音コイン 製造・発送ランブック (2026-08-06)

対象: kind=`nfc_coin` の manual 注文 (OTO音コイン8種 + 声のかたち `KOENOKATACHI-AGENT-NFC-COIN-*`)。
ジョブ基盤 = `/work` (store/src/work.rs)。ワーカー承認は `/admin/work/approve?id=&token=ADMIN_TOKEN`。

## 1. 材料 (ハード要件 — 2026-06-04 優貴指示「洗濯OKに作り直して」)

- **必須**: 防水・エポキシ封止 (または PVC/シリコン一体成型) の **NTAG213 ディスク**。
  PET/紙シール型は不可 (商品説明が「giに付けたまま洗濯機OK」を約束済み。シールは洗濯1回で死ぬ)。
- 調達候補 (2026-08-06 検索): **ctunk エポキシ樹脂タイプ NTAG213/144B 防水 25mm** (Amazon.co.jp、
  単品〜複数枚パック、色数種)。⚠価格・在庫は注文時に要確認。
- ⚠現物到着後、**洗濯耐久テスト** (書込→ロック→洗濯機数サイクル→読めるか) を一度やってから
  「洗濯機OK」の商品を出荷すること。乾燥機NG (NTAG213 温度上限~85℃) はコピー明記済み。

## 2. 書き込むURLの規約

- OTO音コイン: 商品 description_ja 記載の `oto.html?s=KEY` から導出 (従来規約)。
- 声のかたち「ありがとう」コイン: `https://koe.live/api/post-audio/2c7e70e0856a35d3e48a3b3d969dd6bd6b8aff0543ff29406c00e4d5763caaff`
  (実体 = koe-voice R2 `tts/2c7e….mp3`、content-hashキーの恒久オブジェクト。⚠R2掃除系スクリプトの削除対象に入れない)
- カスタム注文 (お客様の声): 受領音声を先に恒久保存してから書く。手順:
  1) 注文確認メールへの返信で音声受領 (10秒まで・同意文言はLPに明記済み)
  2) mp3化して R2 koe-voice `tts/<sha256(音源)>.mp3` に put (koe-edge の post-audio 配信規約に乗る)
  3) URL = `https://koe.live/api/post-audio/<sha256>` を疎通確認してから書込み

## 3. 書き込み手順 (NFC Tools アプリ・iPhone/Android)

1. NFC Tools → 書く → レコード追加 → URL → 上記URLを入力 → 書く (コインにかざす)
2. 読取テスト: かざして Safari が開き音声が再生されること
3. **読取専用ロック (必須・不可逆)**: NFC Tools → その他 → 「読み取り専用にする」→ かざす
   (URLは書込後ロック=改ざん不可、と商品説明で約束済み。ロック忘れ出荷は禁止)
4. ロック検証: もう一度書込みを試みて失敗することを確認

## 4. 発送

- ワーカー経由: `/work/queue?token=` で注文claim → 書込→梱包→発送 → `/api/work/ship` で追跡番号
  (顧客への発送メール自動送信・報酬 WORK_FEE_JPY 既定¥300/件)
- 自前発送: catalog_orders.status を manual_pending → shipped へ (workフロー準拠)

## 4.5 ワーカー直送キット方式 (2026-08-06 優貴さん発案)

コイン等の材料は優貴さんの手元を経由せず**ワーカー宅へ直送**し、ワーカーが書込→台紙セット→梱包→発送まで完結する。

**キット内容 (BOM)**:
1. 防水エポキシ NTAG213 コイン 25mm (ctunk・Amazonからワーカー宅へ直送・まず10枚)
2. ブランド台紙 A6 = `docs/kit/knk_card_a6.png` (300dpi・黒地金波形・中央にコイン取付ガイド円「ここに、声。」)。
   ネット印刷 (ラクスル等・マット紙 A6) でワーカー宅へ直送、または自宅印刷
3. 両面グルードット (コインを台紙中央に固定・Amazon)
4. OPP袋 (台紙+コインを入れる・A6サイズ) + クッション封筒 小 (Amazon)
5. 手順書 = 本ランブック §2-§4 を印刷 or メールで送付

**フロー**: 応募承認 (人間) → 承認メールでキットお届け先住所を伺う → Amazon/ラクスルで直送手配 →
到着後、練習1枚 (自分のスマホで書込→ロック→再生確認) → `/work/queue` で実注文の受付開始。
⚠初回のみ: 洗濯耐久テストは優貴さん側でも1枚実施してから「洗濯機OK」商品の出荷を解禁する。

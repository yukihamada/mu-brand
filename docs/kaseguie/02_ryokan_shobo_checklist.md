## 0. なぜ「簡易宿所」か
- **民泊新法(住宅宿泊事業)= 年180日上限** → 「めちゃ稼ぐ」前提の通年稼働に不向き。
- **旅館業法 簡易宿所営業 = 日数上限なし(通年OK)** → こちらで取る。採算シートの前提。

## 1. 旅館業(簡易宿所)許可 — 建物・運営要件
- [ ] **用途・地域**: 旅館業可能な区域か(美留和=無指定でも自治体条例/農地転用に注意) → 弟子屈町・保健所確認
- [ ] **客室・構造**: 簡易宿所の面積/採光/換気/天井高 → BIMは houki 全項目OK(採光0.53・換気1.54回/h)だが**旅館業基準で再確認**
- [ ] **便所・洗面・浴室**: 収容人数に応じた数 → BIMにUB+洗面+トイレあり(小規模は充足見込み)
- [ ] **宿泊者名簿**: 備付け義務(電子可)
- [ ] **消防法令適合通知書**: 旅館業許可の**前提**。消防に申請→交付(下記2)

## 2. 消防(旅館業=消防法 別表(5)項イ・特定防火対象物)
- [ ] **自動火災報知設備**: 旅館業は**全施設で必要**(面積問わず)。
      ⚠ BIMの「住宅用火災警報器」は別物 → **特定小規模施設用自動火災報知設備**(木造2階・延床300㎡未満なら簡易・相互連動型が使える見込み)に**要アップグレード**
- [ ] **誘導灯**: 宿泊施設は義務 → BIMに**未計上 → 追加要**(避難口誘導灯)
- [ ] **消火器**: 150㎡未満は義務外だが設置(BIMに2本あり)
- [ ] **避難経路図 室内掲示** / 2方向避難の確認(2Fロフト→階段+非常時動線)
- [ ] スプリンクラー: 小規模住宅型は通常不要(面積/構造で確認)
- [ ] 防火管理者: 収容30人未満は通常不要(規模確認)

## 3. 無人運営(ICT帳場代替)— 2025/4 改正対応
2025年4月から**簡易宿所にも玄関帳場要件**が適用。無人にするには下記3点を**全て**満たす(厚労省):
- [ ] **緊急時の迅速対応体制**: 事故/急病時に駆けつけ可能な距離の管理者・委託先(StayFlow運営+地元委託)
- [ ] **本人確認**: 営業者設置の**ビデオカメラ等で顔+顔写真付き公的書類(免許/パスポート/マイナ)を常時鮮明画像で確認**
- [ ] **鍵の受渡しを適切に**: スマートロック(予約連動QR/暗証)
- [ ] **⚠ 自治体上乗せ条例の確認**: 京都市等は簡易宿所のフロント代替を原則不可。**北海道/弟子屈の条例を必ず確認**

### ⚠ 設計コンセプトとの矛盾(正直に)
- 当初「**カメラレス**(IKI思想・プライバシー)」を掲げたが、**ICT帳場代替は玄関での本人確認ビデオが法的に必須**。
- 解決: **玄関(チェックイン)だけカメラ**(法要件)、**居室・寝室・サウナ・浴室は無カメラ**(プライバシー)。これで両立。

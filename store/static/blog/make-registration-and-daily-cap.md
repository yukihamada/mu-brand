# 「作る」に登録必須 + 1日5点までにした話

> 2026-08-28 · #015 · ポリシー変更

これまで MU MAKE (`/make`) は、 サイトでもアプリでも、 誰でも登録なしにその場で AI 生成→出品できました。
今日からこれをやめます。 **作るにはメール登録 (6桁コード・10秒・パスワードなし) が必須。 1人1日 5点まで。**

---

## なぜ変えるか

登録なし・無制限は 「言うだけで作れる」 という体験としては最速でした。
が、 運営してみて分かったコストは 2 つです。

- **無断使用・著作権丸投げのリスク** — 誰の生成かが分からないと、 権利侵害があったときに追跡・是正する手段がない。
- **無制限生成の濫用耐性の低さ** — 匿名だと 1 人が使い捨てで大量生成しても止める理由がなく、 Gemini 生成費 (¥12/枚) が際限なく漏れる。

これは 「作る」 という MU の中核体験を弱くする変更ではなく、 **誰が作ったかを分かるようにする** 変更です。
デザインを見るのは今まで通り無料・登録不要。 買うのも今まで通り登録不要です。 変わるのは 「作る」 ボタンを押す瞬間だけ。

---

## 何が変わるか

| 項目 | これまで | これから |
|---|---|---|
| デザインを見る | 登録不要 | 登録不要 (変わらず) |
| 買う | 登録不要 | 登録不要 (変わらず) |
| **作る** (`/make`・リミックス) | 登録不要 | **メール登録必須** |
| 登録の手間 | — | メール → 6桁コード → 完了 (10秒・パスワードなし) |
| 作れる数 | 実質無制限 (IP単位の時間制限のみ) | **1人1日 5点まで** |

登録は既存の MU アカウント (メール認証・API key) と同じ仕組みです。 新しいアカウント種別は増えていません。
一度登録すれば、 サイトでもアプリでも、 その端末・そのログインのままずっと使えます。

---

## 実装

- サイト (`wearmu.com/make`): 未登録で「作る」を押すと、 その場でメール認証カードが開きます。 コードを入れれば自動でさっきの依頼を作り直します。 離脱なし。
- アプリ (MU iOS): 同じ導線。 未登録で作ろうとすると登録シートが開き、 完了次第そのまま生成を再開します。
- 1日5点の上限は 「作った人」 単位 (メールアドレス) で数えます。 `/make` と 「一言足して、 変える」 (リミックス) の合算です。 IP や端末単位ではないので、 複数端末で使っても抜け道にはなりません。

コードはこれまで通り [GitHub](https://github.com/yukihamada/mu-brand) に公開しています。 該当箇所は `store/src/catalog.rs` の `require_maker_email` / `check_daily_make_cap`。
